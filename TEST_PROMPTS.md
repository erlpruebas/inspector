# Prompts de prueba para Inspector

Estos prompts estan pensados para probar peticiones unicas, voz, alarmas, adjuntos recientes y seleccion explicita de Codex Desktop. Usalos desde la ventana Tkinter o por Telegram.

## Basicos

1. `Resume este texto en una frase: El equipo comercial ha pedido revisar la propuesta antes del jueves porque el cliente quiere comparar tres escenarios de coste.`

2. `Convierte esto en tres tareas claras: revisar el contrato, confirmar precios con proveedores y enviar una respuesta al cliente.`

3. `Redacta un correo breve y amable para decir que hemos recibido la documentacion y la revisaremos hoy.`

## Modo one-shot

4. `Quiero preparar una respuesta formal a un cliente que se queja de un retraso de entrega. Redacta la respuesta final directamente.`

5. `Crea una lista de comprobacion para cerrar una factura mensual y guardala en markdown si hace falta.`

6. `Analiza este escenario: tenemos tres presupuestos, uno barato con riesgo alto, uno medio equilibrado y uno caro con garantia extendida. Prepara una recomendacion ejecutiva para direccion.`

## Adjuntos recientes

7. `Analiza lo que te acabo de enviar y dame una tabla con hallazgos, riesgos y siguientes acciones.`

8. `Con los ultimos archivos adjuntos, crea un resumen ejecutivo y menciona que archivos has usado.`

## Codex Desktop explicito

9. `Quiero que me ejecutes con Codex de escritorio: prepara esta tarea visual y detenla si aparece login o confirmacion sensible.`

## Voz

10. `configuracion kokoro`

11. `configuracion eleven labs`

12. `Lee en voz alta una respuesta de 30 segundos explicando que hemos entendido la peticion y que vamos a revisar el informe.`

## Alarmas

13. `Avisame dentro de diez minutos para revisar si ya he contestado al cliente.`

14. `Avisame dentro de media hora entregandome un informe breve de cuales son las materias primas actualmente mas cotizadas y por que pueden estar subiendo.`

15. `Recuerdame dentro de dos minutos que haga una prueba rapida de confirmacion por voz.`

16. `Que alarmas hay`

17. `Pospone la alarma 1 media hora`

18. `Cancela la alarma 1`

## Ofimatica avanzada

19. `Tengo que convertir notas desordenadas de una reunion en un acta. La reunion trato de presupuesto, plazos, riesgos y responsables. Redacta el acta final directamente.`

20. `Prepara una tabla con columnas: tarea, responsable, fecha limite, riesgo, siguiente accion. Usa estos datos: Marta revisa proveedores manana, Luis cierra presupuesto el viernes, Ana valida el contrato el lunes.`

21. `Quiero un informe de una pagina sobre el estado de una oficina nueva. Incluye resumen ejecutivo, riesgos, decisiones pendientes, tareas por area y un correo final para enviar al equipo.`
