# Inspector Agent 2.2

Versión autocontenida y portable del agente Inspector, reconstruida para lograr paridad operativa integral, routing por capacidades estructuradas y control exhaustivo de cuota de Codex.

## Instalación

```bash
cd agent_v2_2
pip install -e .
```

Copia `.env.example` a `.env` y rellena las claves necesarias.

## Arranque

```bash
agent-v2-2 start
```
