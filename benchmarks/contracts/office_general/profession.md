# Profession Contract

## Id
office_general

## Title
Ofimatica transversal para asistente ejecutivo

## Description
Conjunto de tareas de oficina y coordinacion que un ejecutivo o profesional puede delegar en un asistente: correo, agenda, documentos, tablas, seguimiento, priorizacion y reportes.

## Scope

- emails
- agenda
- documentos
- tablas
- seguimiento
- priorizacion
- reportes
- archivo sintetico

## Constraints

- No inventar datos.
- Priorizar trazabilidad y claridad.
- Pedir aclaracion si falta un dato esencial.
- Mantener tono profesional y util.

## Evaluation Dimensions

- correctness
- format
- traceability
- tone
- completeness

## Output Standard

- Respuesta breve, util y verificable.
- Tono profesional.
- Trazabilidad con archivos locales cuando aplique.
