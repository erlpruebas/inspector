# Opciones de SSO para Barna Health
Barna Health necesita un proveedor de SSO para mejorar la experiencia de sus usuarios y la seguridad de su organización. A continuación, se presentan algunas opciones de proveedores de SSO que podrían ser adecuadas para Barna Health.

## Proveedores de SSO
1. **Logto**: Es un proveedor de IAM de código abierto que ofrece autenticación y autorización para aplicaciones web y móviles.
2. **Keycloak**: Es un proveedor de IAM de código abierto que ofrece autenticación y autorización para aplicaciones web y móviles.
3. **NextAuth**: Es un proveedor de IAM de código abierto que ofrece autenticación y autorización para aplicaciones web y móviles.
4. **Casdoor**: Es un proveedor de IAM de código abierto que ofrece autenticación y autorización para aplicaciones web y móviles.
5. **SuperTokens**: Es un proveedor de IAM de código abierto que ofrece autenticación y autorización para aplicaciones web y móviles.

## Características de los proveedores de SSO
* **Autenticación**: Todos los proveedores ofrecen autenticación mediante contraseñas, biometría y inicio de sesión social.
* **Autorización**: Todos los proveedores ofrecen autorización basada en roles y políticas.
* **Gestión de usuarios**: Todos los proveedores ofrecen gestión de usuarios, incluyendo aprovisionamiento, roles y auditorías.
* **Gestión de organizaciones**: Todos los proveedores ofrecen gestión de organizaciones, incluyendo estructuración de equipos, permisos y multi-tenencia.
