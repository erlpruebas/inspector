# Alternativas a herramienta de encuestas para GreenBox
Existen varias alternativas a herramientas de encuestas que pueden ser económicas y efectivas para GreenBox. A continuación, se presentan algunas opciones:

## 1. Jotform
Jotform es una plataforma de formularios en línea que ofrece una variedad de plantillas y herramientas para crear encuestas personalizadas. Es fácil de usar y ofrece una versión gratuita, lo que la hace una excelente opción para pequeñas y medianas empresas.

## 2. QuestionPro
QuestionPro es una plataforma de encuestas en línea que ofrece una variedad de herramientas y características para crear encuestas personalizadas. Ofrece una versión gratuita y planes de pago para empresas de todos los tamaños.

## 3. Survicate
Survicate es una plataforma de encuestas en línea que se enfoca en la segmentación y personalización de las encuestas. Ofrece una versión gratuita y planes de pago para empresas de todos los tamaños.
