## Recomendaciones de Control Interno

### 1. Sistema de Prevención de Duplicados
- Implementar validación en tiempo real que alerte sobre transacciones idénticas (mismo concepto, fecha e importe)
- Establecer procedimiento de aprobación para gastos >€150
- Requerir número de factura único para cada transacción

### 2. Proceso de Documentación Obligatoria
- Política de "sin recibo, sin reembolso"
- Digitalización obligatoria de recibos mediante app móvil
- Plazo máximo de 48 horas para cargar documentación

### 3. Verificación de Proveedores
- Crear lista autorizada de proveedores por categoría
- Implementar proceso de onboarding para nuevos proveedores
- Revisión trimestral de proveedores recurrentes

### 4. Control de Discrepancias
- Sistema de alertas para diferencias >10% entre importe declarado y esperado
- Flujo de aprobación de dos niveles para discrepancias
- Reporte mensual de ajustes y variaciones

### 5. Límites y Autorizaciones
- Establecer límites por categoría:
  - Viajes: €200 máximo por transacción
  - Comidas: €100 máximo por persona
  - Software: Aprobación IT obligatoria
- Implementar matriz de autorizaciones según montos
