# Alternativas económicas a herramientas de encuestas para GreenBox

Basándome en las notas de voz y la investigación web disponible, se identificó la necesidad de buscar una alternativa barata a una herramienta de encuestas para GreenBox (nota VN-009 del 6 de mayo de 2026).

## Alternativas económicas recomendadas

### 1. **Google Forms** (Gratuito)
- **Fuente:** Jotform (2025) la identifica como "Mejor para límites de uso" entre las alternativas a SurveyMonkey.
- **Características:** Completamente gratuita, integración con Google Workspace, límites generosos para uso básico.
- **Ideal para:** Empresas que necesitan una solución sin costo inicial.

### 2. **Jotform** (Plan gratuito disponible)
- **Fuente:** Jotform (2025) se posiciona como "Mejor para uso general" entre las alternativas a SurveyMonkey.
- **Características:** Plan gratuito con 5 formularios, 100 respuestas mensuales y 100MB de almacenamiento.
- **Ventaja:** Interfaz intuitiva y plantillas personalizables.

### 3. **Crowdsignal** (antes Polldaddy)
- **Fuente:** Jotform (2025) la identifica como "Mejor en precios" entre las alternativas a SurveyMonkey.
- **Características:** Plan gratuito disponible, precios competitivos para planes premium.
- **Especialización:** Encuestas, votaciones y cuestionarios simples.

### 4. **LimeSurvey** (Opción de código abierto)
- **Fuente:** Jotform (2025) la identifica como "Mejor en personalización" entre las alternativas a SurveyMonkey.
- **Características:** Software de código abierto que se puede autohospedar gratuitamente.
- **Consideración:** Requiere recursos técnicos para instalación y mantenimiento.

### 5. **QuestionPro** (Plan gratuito)
- **Fuente:** QuestionPro (2026) aparece como alternativa a Microsoft Forms con funciones competitivas.
- **Características:** Plan gratuito con encuestas básicas, informes y exportación de datos.
- **Ventaja:** Soporte para múltiples idiomas según Jotform (2025).

## Consideraciones para GreenBox

Según el contexto de las notas de voz, GreenBox parece ser una empresa con necesidades operativas diversas (facturación, contratos, reuniones con clientes). Para una solución económica se recomienda:

1. **Google Forms** si la prioridad es costo cero y simplicidad
2. **Jotform** si se necesita más personalización manteniendo un plan gratuito
3. **QuestionPro** si se anticipa crecimiento y necesita funciones multilingüe

Todas estas opciones permiten comenzar sin inversión inicial y escalar según las necesidades futuras de GreenBox.
