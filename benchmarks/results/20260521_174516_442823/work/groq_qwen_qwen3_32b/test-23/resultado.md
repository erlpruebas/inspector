# Proveedores de SSO recomendados para Barna Health

## Análisis basado en contexto web y necesidades técnicas

### 1. **EMÚ OneIdP**  
- **Especialidad**: Solución SSO con gestión de identidades empresariales  
- **Ventajas**:  
  - Integración con sistemas de gestión de dispositivos (MDM)  
  - Soporte para industrias reguladas como salud  
  - Escalabilidad para empresas en crecimiento  
- **Fuente**: [Scalefusion - Top SSO 2026](https://blog.scalefusion.com/es/las-mejores-soluciones-sso/)  

### 2. **Keycloak (Red Hat)**  
- **Especialidad**: Plataforma de código abierto para IAM  
- **Ventajas**:  
  - Autenticación federada y SSO multi-proveedor  
  - Soporte para protocolos SAML y OAuth 2.0  
  - Integración con sistemas legacy y cloud  
- **Fuente**: [Logto - IAM Open Source 2025](https://blog.logto.io/es/top-oss-iam-providers-2025)  

### 3. **Logto**  
- **Especialidad**: Plataforma de autenticación moderna  
- **Ventajas**:  
  - Interfaz de usuario personalizable  
  - Soporte para autenticación social y multifactor  
  - Arquitectura modular para adaptación a flujos de trabajo sanitarios  
- **Fuente**: [Logto - IAM Open Source 2025](https://blog.logto.io/es/top-oss-iam-providers-2025)  

### 4. **Veltar**  
- **Especialidad**: Soluciones BYOD y gestión de dispositivos  
- **Ventajas**:  
  - Seguridad en entornos móviles (crítico para clínicas)  
  - Control de acceso basado en roles  
  - Integración con sistemas de gestión de TPV  
- **Fuente**: [Scalefusion - Top SSO 2026](https://blog.scalefusion.com/es/las-mejores-soluciones-sso/)
