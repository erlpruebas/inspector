OpciónGratis / límitePago aproximadoComentario práctico
Gemini 2.5 Flash TTS Free tier disponible; límites reales visibles en AI Studio. $0.50 / 1M tokens input, $10 / 1M tokens audio. Mi candidata principal para el asistente.
Gemini 2.5 Pro TTS Sin free tier estándar en la tabla consultada. $1 / 1M input, $20 / 1M audio. Más cara; usar solo si gana claramente en voz.
Gemini 3.1 Flash TTS Preview Free tier disponible; preview con límites variables. $1 / 1M input, $20 / 1M audio. Buena para experimentar, menos estable por ser preview.
ElevenLabs Plan gratis: 10k créditos/mes. API incluida incluso en free. Depende de plan/modelo; V2 Multilingual suele ser 1 crédito/caracter, Flash/Turbo V2.5 baja a 0.5-1 crédito/caracter. Excelente calidad, pero hay que renovar la clave.
Groq TTS Cuenta gratuita para probar, con límites del plan. Orpheus English $22 / 1M caracteres; Arabic $40 / 1M caracteres. No es buena ruta para español hoy.
Groq STT Cuenta gratuita con límites; archivos hasta 25 MB en free tier según docs. Whisper Turbo $0.04/h transcrita; Whisper Large v3 $0.111/h. Muy buena ruta si la clave queda operativa.
Edge TTS Sin clave ni coste directo en edge-tts. No hay tarifa API formal para este wrapper. Útil para pruebas y uso personal, cuidado en producción.
Piper / Kokoro / Windows SAPI / Whisper local Ilimitado en API: corre en tu máquina. Coste local de CPU/GPU y almacenamiento. La ruta privada y robusta para fallback.
